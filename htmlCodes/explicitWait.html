Selenium Explicit Wait Practice Lab

This page is created for practicing Selenium WebDriverWait and ExpectedConditions.

Each section contains a Positive and Negative use case.

1. Presence Of Element Located

Click the button. A new element will be added to the DOM after 6 seconds.

Positive Use Case

Click the button and wait for the dynamic element with a maximum wait of 10 seconds.

Negative Use Case

Click the button and wait for only 2 seconds. The dynamic element will not be available within the wait time.

2. Visibility Of Element Located

The element already exists in the DOM but is initially hidden. After clicking the button, it becomes visible after 5 seconds.

🎉 Now I am Visible!

Positive Use Case

Wait for 10 seconds. The hidden element should become visible.

Negative Use Case

Wait for only 2 seconds. The element will still be hidden.

3. Invisibility Of Element Located

The loader is visible initially. After clicking the button, it will disappear after 5 seconds.

⏳ Loading... Please Wait

Positive Use Case

Wait for 10 seconds. The loader should become invisible.

Negative Use Case

Wait for only 2 seconds. The loader should still be visible.

4. Element To Be Clickable

The button is initially disabled. It becomes enabled after 5 seconds when the page loads.

Positive Use Case

Wait for 10 seconds. The button should become clickable.

Negative Use Case

Reload the page and wait for only 2 seconds. The button should still be disabled.

5. Alert Is Present

Click the button. An alert will appear after 5 seconds.

Positive Use Case

Click the button and wait for 10 seconds. The alert should appear.

Negative Use Case

Click the button and wait for only 2 seconds. The alert should not appear within the wait time.

6. Frame To Be Available And Switch To It

Selenium can wait for this frame and switch into it.

Positive Use Case

Wait for the existing frame and switch into it.

Negative Use Case

Try to switch to a frame ID that does not exist. Selenium should throw TimeoutException.

Positive Use Case

The message will change after 5 seconds.

Positive Use Case
